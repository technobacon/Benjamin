# Final Scripts

Store approved, ready-to-record scripts here as `YYYY-MM-DD-topic-slug.md`.

Move a script into this folder only after the research cutoff is recorded, citations and calculations are verified, all unresolved claims are removed or labelled, and the narration has been read aloud at least once.

Published scripts may remain here as an archive. Record material post-publication corrections in the script file with the correction date.
